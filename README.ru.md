# dsh-telegram-bridge — форк с локализацией

[English](README.md) | [Русский](README.ru.md) | [Tiếng Việt](README.vi.md)

Полноценное двустороннее управление DeepSeek Harness (DSH) через Telegram: промпты, голосовые сообщения, скриншоты, git diff, shell-команды, подтверждение инструментов и уведомления macOS — **с интерфейсом на русском, английском и вьетнамском**.

> Это форк оригинального [datit309/dsh-telegram-bridge](https://github.com/datit309/dsh-telegram-bridge).
> Оригинал содержит все строки интерфейса на вьетнамском прямо в коде; здесь они вынесены в словари.

---

## Что добавлено в форке

### 1. Полноценная локализация (i18n)

Все пользовательские строки вынесены из кода в словари `locales/`:

| Файл | Строк |
|---|---|
| `locales/ru.js` | 231 |
| `locales/en.js` | 231 |
| `locales/vi.js` | 231 |

Каждая строка — стабильный ключ (хеш исходного литерала) плюс позиционные плейсхолдеры `{0}`, `{1}`:

```js
// i18n.js
export function t(key, args) { ... }     // "⏳ *DSH [{0}]*: Agent занят. Запрос в очереди: _\"{1}\"_"
export function phrase(slot) { ... }     // для строк вне каталога (схема настроек, список команд)
```

Места вызова в `index.js` остаются читаемыми:

```js
await tgSend(t('sce4692f3', [project, truncate(text, 60)]));
```

### 2. Выбор языка, синхронный с DSH

В настройках плагина появилось поле **Язык**:

- `auto` (по умолчанию) — следует языку интерфейса DSH;
- `ru` / `en` / `vi` — жёстко заданный язык.

При переключении языка в DSH бот меняет язык на лету и **перерегистрирует список команд в Telegram** (`setMyCommands`), поэтому меню `/` в чате тоже становится русским.

Даты в подписях сообщений форматируются по выбранной локали (`ru-RU`, `en-US`, `vi-VN`).

### 3. Переведена панель настроек

Веб-панель плагина (`client.js`) тоже локализована и содержит селектор языка. Клиентский бандл не может импортировать серверный `i18n.js`, поэтому панель несёт собственный компактный словарь.

## Установка

```bash
# в каталоге профиля DSH
dsh plugin add github:<ваш-ник>/dsh-telegram-bridge
```

Или вручную — добавьте в `package.json` профиля:

```json
{
  "dependencies": {
    "dsh-telegram-bridge": "github:<ваш-ник>/dsh-telegram-bridge"
  }
}
```

Для локальной разработки удобнее симлинк:

```bash
ln -sfn /путь/к/форку ~/.dsh/profiles/web/node_modules/dsh-telegram-bridge
```

> При использовании симлинка убедитесь, что в `package.json` профиля зависимость указывает на `file:`, иначе установщик перезапишет каталог копией из GitHub.

## Настройка

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите Token.
2. Откройте **Настройки → Telegram & Notifier** в DSH.
3. Вставьте Token, выберите язык, нажмите **Сохранить настройки**.
4. Отправьте боту `/start` — Chat ID привяжется автоматически.

## Команды бота

| Команда | Действие |
|---|---|
| `/sessions`, `/switch <номер>` | Список сессий и переключение |
| `/workspaces`, `/cd <путь>` | Рабочие директории |
| `/model` | Просмотр и смена AI-модели |
| `/diff` | Изменения в коде (Git Diff) |
| `/commit <msg>` | Commit & push |
| `/sh <команда>` | Shell-команда (0 токенов) |
| `/get <file>` | Скачать файл в Telegram |
| `/files` | Изменённые файлы с кнопками |
| `/mute`, `/unmute` | Звук Mac |
| `/new`, `/status`, `/stop`, `/help` | Управление сессией |

Плюс: голосовые сообщения (распознавание речи), фото/скриншоты (vision), документы.

## Как добавить язык

Язык живёт в **четырёх местах двух файлов**: серверный словарь (`locales/`) и словарь
панели настроек (`client.js`, который не может импортировать серверный модуль).
Скрипт делает всю обвязку за вас:

```bash
node scripts/add-locale.mjs de Deutsch de-DE
```

Он создаёт `locales/de.js` (239 ключей, значения скопированы с английского),
регистрирует словарь в `i18n.js` (импорт, `LOCALES`, `LANGUAGES`, `DICTS`,
`dateLocale`) и добавляет словарь панели плюс опцию в селектор `client.js`.
Затем проверяет синтаксис всех затронутых файлов и печатает, сколько ключей
ещё требует перевода.

Аргументы валидируются (`deu`, `DE`, `auto` и некорректный тег даты отклоняются
сразу), а повторный запуск с тем же кодом ничего не меняет.

Дальше правите только `locales/<код>.js` и блок `<код>` в `client.js`.

## Структура

```
index.js          серверная часть плагина (0 захардкоженных строк интерфейса)
client.js         веб-панель настроек + селектор языка
i18n.js           t() / phrase(), выбор языка, локаль дат
locales/ru.js     русский
locales/en.js     английский
locales/vi.js     вьетнамский (оригинал автора)
cordis.patch.yml  манифест для загрузчика DSH
```
